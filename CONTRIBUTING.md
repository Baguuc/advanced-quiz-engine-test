# Contributing

Kilka prostych zasad dotyczących pracy z repozytorium.

## 1. Trello

Każdy nowy feature powinien mieć swoją kartę na Trello.

Dodaj kartę z numerem i krótkim opisem tego, co planujesz zrobić, np.:

> `#67 Zmiana layoutu strony głównej`

## 2. Branch

Nowego brancha zawsze twórz od `staging`.

Nazwij go według schematu:

```text
feat/<numer>-<krótki-opis>
```

Przykład:

```text
feat/67-homepage-layout
```

## 3. Pull Request

Po skończeniu pracy otwórz Pull Request do `staging`.

Branche `main` i `staging` są zablokowane, więc **nie pushujemy bezpośrednio na nie**.
